# GreenVRP Web Console

GreenVRP Engine 的新前端原型：React + Vite + TypeScript + Tailwind CSS。深墨绿、纸白与青柠的视觉系统，Instrument Serif / Noto Serif SC 编辑感排版，以及动态路线场 Hero。

> 这是一个独立前端，现有 Streamlit 界面（`../frontend/`）保持不变。

## 运行

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # 生产构建
```

## 两种解算模式

### 本地演示（默认）

- 内置北京 100 个配送节点样例数据。
- 浏览器内贪心路径构造，用于展示交互与五维成本模型。
- 载重相关油耗：额定油耗按 50% 载重计，空载 0.75×、满载 1.25×，按每段剩余载重累计。
- 浏览器演示为静态速度简化版；早晚高峰时变速度在真实引擎中生效。
- 界面会明确标注「本地演示解算」；结果**不是** OR-Tools 最优解。

### 真实引擎

1. 安装 Python 依赖并启动 FastAPI：

   ```bash
   uvicorn api.main:app --host 0.0.0.0 --port 8000
   ```

2. 打开页面右上角的「演示模式」或控制台的「连接设置」。
3. 填写 API 地址与 Key，测试连接后保存并启用。
4. 默认开发配置：
   - API 地址：`http://localhost:8000`
   - API Key：`green-vrp-default-key-2024`（见 `config/security.py`）
   - 后端 CORS 默认允许 `http://localhost:3000`

连接成功后，控制台会切换为 OR-Tools 求解，结果区标记「真实引擎 · FastAPI」。真实引擎采用时变速度 + 多策略求解 + 载重感知二次精修 + 车队缩减 + 多种子 ALNS + 发车时刻优化：早晚高峰按速度剖面降速，首轮按工作日平均速度和代表载重求解，随后用每辆车上一轮的实际载重率重建目标再求解；再用缩减一辆车的方案重新求解，最后由多个随机种子的自适应大邻域搜索（IALNS/ALNS）继续破坏-修复，其中一组优先以早高峰结束时刻发车，并对候选路线池做集合划分重组、2-opt*/VND 跨路线精修，最后为每条路线选择避开高峰、减少等待的最优发车时刻，按完整成本保留更优方案。首版解会分别按“优化前成本最优”和“短 ALNS 探针最优”两条路径完整精修，再按真实五维成本择优，避免只看首轮成本选错搜索盆地；最终解还会逐对路线做 CP-SAT 精确重排（容量、时间窗、18:00 返回、白天速度），只保留真实成本更优的配对。

## 功能

- 全屏动态 Hero：等高线、流动路线、移动车辆光点、滚动视差。
- 可交互优化控制台：碳价、油价、时薪、迟到罚金、求解预算、可扩展车队编成。
- 车队编成支持直接输入车辆数量，编辑每种车型的载重、发车成本、百公里油耗与平均速度，并可新增/删除自定义车型（总数上限 15 辆）。
- 动画结果仪表盘：五维成本环图、抽象路线地图、逐站行车清单、时间分解、碳排基线对比。
- 真实引擎支持碳价、油价、迟到罚金、固定成本、载重相关油耗和早晚高峰时变速度，并执行载重感知二次精修 + 车队缩减 + 多种子 ALNS + 发车时刻优化。
- 方案 JSON 导出、路线高亮联动、API 连接测试。
- 响应式布局、键盘焦点、`prefers-reduced-motion` 支持。
